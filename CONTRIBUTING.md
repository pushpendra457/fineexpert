# Contributing to FineExpert

## Branching Strategy
1. Never push directly to `main`.
2. Create dedicated feature branches:
   - `feature/about-page`
   - `feature/auth`
   - `feature/frontend`
   - `feature/backend`
   - `feature/chat`
   - `feature/rag`
   - `feature/dashboard`
   - `feature/profile`
   - `feature/admin`
3. Open a Pull Request into `main`.
4. Ensure all CI checks (linting, tests, build) pass before merging.
